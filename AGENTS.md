# Instrucciones del repositorio — Escuela de Repostería Risco

Aplicar estas reglas a todo cambio del repositorio.

## Producto
- Sitio estático, orientado a confianza y consultas de talleres presenciales en español de Perú.
- Usuarios principalmente móviles que llegan desde redes sociales.
- Entrega limitada a código GitHub y URL PREVIEW. No pagos, backend, dominio definitivo o lanzamiento comercial final.

## Skills locales de lectura obligatoria
1. `.agents/skills/reposteria-direccion-de-arte/SKILL.md` para interfaz y dirección editorial.
2. `.agents/skills/reposteria-confianza-inscripciones/SKILL.md` para veracidad, fuentes, fotografía y CTAs.
3. `.agents/skills/reposteria-auditoria-preview/SKILL.md` antes de declarar un cambio terminado o publicar demo.

## Límites de verdad
- No inventar nombre legal, dirección exacta, teléfonos, horarios, precios, certificados, testimonios, trayectoria, cifras o disponibilidad.
- No representar fotos de stock/IA como escuela real. Registrar origen/licencia/consentimiento; evitar exposición de personas menores.
- Distinguir talleres históricos de talleres con inscripción abierta.
- Toda información editable debe estar en fuentes de datos tipadas; valores no confirmados no se publican.

## Ingeniería
- Preferir Astro + TypeScript + Tailwind con salida estática. JavaScript mínimo.
- Mobile-first, semántica, accesibilidad, rendimiento y diseño editorial no genérico.
- Sin secretos en git, sin push forzado, sin despliegue `--prod`.
- Capturas e informes de prueba reales, nunca ficticios.
